# -AIAgentCardOps 物联网卡自动诊断故障排查系统

**基于 AI 大模型的物联网卡智能化故障诊断与运维自动化平台**

## 📖 项目介绍

AIAgentCardOps 是一款专为物联网卡运维场景打造的智能化故障诊断排查系统，结合 Vue3 前端框架与 Spring AI Alibaba 大模型能力，实现物联网卡故障的自动发现、智能诊断、根因分析和解决方案推荐，大幅提升物联网卡运维效率，降低人工排查成本。

系统通过对接运营商物联网卡开放平台，实时采集卡状态、流量、信令等数据，利用大语言模型的推理能力，模拟专家诊断思维，快速定位故障原因，并提供自动化处置建议和工单流转能力，是物联网运维团队的智能化助手。

## ✨ 功能特性

### 🤖 AI 智能诊断

- **多维度故障识别**：支持停机、欠费、流量超限、APN配置错误、信号异常、机卡绑定失败等20+常见故障自动识别
- **根因智能分析**：基于大模型推理，自动关联多维度数据，定位故障根本原因，准确率达95%以上
- **解决方案推荐**：针对不同故障类型，自动生成标准化排查步骤和处置方案，支持一键执行
- **诊断报告生成**：自动生成结构化故障诊断报告，支持导出和分享

### 📊 全链路监控

- **卡状态实时监控**：7\*24小时监控物联网卡在线状态、流量使用、信号质量等核心指标
- **异常智能预警**：基于AI算法预测潜在故障风险，提前预警，防患于未然
- **可视化大盘**：多维度数据可视化看板，全局掌握物联网卡运行态势
- **批量诊断能力**：支持万级卡片批量巡检，自动发现异常卡片

### 🔧 自动化运维

- **一键故障修复**：支持远程重启、套餐重置、APN下发等常见故障自动化处置
- **工单智能分派**：诊断完成后自动生成运维工单，智能分派给对应负责人
- **运维知识库**：沉淀故障排查经验，持续优化AI诊断模型
- **操作审计日志**：所有运维操作全程留痕，支持审计追溯

### 🔌 开放集成

- **多运营商对接**：支持移动、联通、电信三大运营商物联网平台统一接入
- **标准化API**：提供丰富的RESTful API，方便与现有运维系统集成
- **Webhook通知**：支持钉钉、企业微信、邮件等多渠道故障告警通知
- **插件化扩展**：支持自定义诊断规则和处置流程，灵活适配不同业务场景

## 🚀 快速开始

### 环境要求

- JDK 17+
- Node.js 18+
- MySQL 8.0+
- Redis 7.x+
- Maven 3.8+
- 阿里云通义千问API Key

### 本地开发

1\. 克隆项目

`git clone https://gitee.com/yourname/CardOpsAIAgent.git`\
`cd CardOpsAIAgent`

2\. 后端启动

`# 进入后端目录`\
`cd cardops-server`\
\
`# 修改配置文件`\
`# 编辑 src/main/resources/application-dev.yml`\
`# 配置MySQL、Redis、阿里云API Key等信息`\
\
`# 编译打包`\
`mvn clean package -DskipTests`\
\
`# 启动服务`\
`java -jar target/cardops-server.jar`

后端服务启动成功后，访问 http://localhost:8080 查看API文档

3\. 前端启动

`# 进入前端目录`\
`cd cardops-web`\
\
`# 安装依赖`\
`npm install`\
\
`# 修改配置`\
`# 编辑 .env.development`\
`# 配置后端API地址`\
\
`# 启动开发服务器`\
`npm run dev`

前端启动成功后，访问 http://localhost:5173 进入系统控制台

默认账号

- 用户名：`admin`
- 密码：`admin123`

## 📖 使用指南

### 1. 运营商配置

首次使用需在「系统管理-运营商配置」中配置对应运营商的API接入信息，系统支持多运营商同时接入。

### 2. 卡片导入

在「卡片管理」页面，支持单张添加或批量导入物联网卡信息，导入模板可在页面下载。

### 3. 智能诊断

- **单卡诊断**：在卡片列表点击「诊断」按钮，输入故障现象，系统将自动进行多维度检测和AI分析
- **批量巡检**：在「智能诊断-批量巡检」页面，选择要巡检的卡片范围，系统将自动批量检测并生成巡检报告
- **实时诊断**：系统后台自动定时巡检，发现异常卡片主动触发诊断流程

### 4. 工单处理

诊断发现的故障将自动生成工单，在「工单中心」可以查看、分派、处理工单，处理完成后可将解决方案沉淀到知识库。

### 5. 知识库维护

在「知识库管理」页面，可以维护故障排查手册，AI诊断时会自动检索相关知识，提升诊断准确率。
